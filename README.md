# Тестовый план

## Объект:

Сайт [netology.ru](netology.ru)

## Цель

Автоматизация тестирования сценариев перехода к форме записи на обучение профессии «Инженер по тестированию» и заполнения этой формы.

### Перечень автоматизируемых сценариев:

1. Главная страница -> страница "Программирование". Реализация через:
   - кнопка в хедере "Каталог курсов" -> пункт меню "Программирование"
   - кнопка в хедере "Каталог курсов" -> строка поиска -> кнопка "Найти курс"
   - первый блок страницы, элемент "Программирование"
   - подвал, меню "Обучение", пункт "Каталог курсов" -> пункт меню "Программирование"
   - подвал, меню "Обучение", пункт "Программирование"
2. Главная страница -> страница "Инженер по тестированию". Реализация через:
   - кнопка в хедере "Каталог курсов" -> строка поиска -> выбор предложения из выпадающего списка
3. Страница "Программирование" -> страница "Инженер по тестированию". Реализация через:
   - выбор из списка предложенных курсов
   - строка поиска -> выбор из списка предложенных курсов
4. Переход к форме записи на странице "Инженер по тестированию". Реализация через:
   - форма доступна на странице без дополнительных действий
   - кнопка "К тарифам" -> кнопка "Записаться"
   - плавающая кнопка "К тарифам" -> кнопка "Записаться"
5. Заполнение формы для авторизованного пользователя (при выборе формы, доступной непосредственно на странице):
   - форма заполнена автоматически данными пользователя
   - нажать "Записаться"
6. Заполнение формы для авторизованного пользователя (при выборе формы через кнопку "К тарифам"):
   - форма заполнена автоматически данными пользователя
   - нажать "Перейти к оплате"
7. Заполнение формы для неавторизованного пользователя (при выборе формы, доступной непосредственно на странице):
   - заполнить поля: имя, телефон, электронная почта
   - поставить галочку "Принимаю условия пользовательского соглашения"
   - нажать "Записаться"
8. Заполнение формы для неавторизованного пользователя (при выборе формы через кнопку "К тарифам"):
   - заполнить поля: имя, телефон, электронная почта
   - поставить галочку "Принимаю условия пользовательского соглашения"
   - нажать "Перейти к оплате"

### Перечень используемых инструментов с обоснованием выбора:

1. IDE IntelliJ IDEA, система сборки Gradle, язык Java (предоставляют все возможности для выполнения задачи, потенциальные исполнители обладают необходимыми навыками).
2. Библиотеки и фреймворки:
  - JUnit5 (реализация непосредственно тестов)
  - Selenide (взаимодействие с элементами страниц)
  - Lombok (улучшение качества кода, уменьшение затрат времени)
  - Faker (генерация рандомных тестовых данных)
  - SLF4J (Simple Logging Facade for Java) (вывод логов прогона тестов в консоль для нахождения возможных ошибок в тестах)
  - Allure (составление хороших отчётов о проведённом тестировании и возможных баг-репортах)
3. Браузер Chrome (собран на базе Chromium, как и Яндекс - самые популярные браузеры)
4. DevTools браузера (поиск элементов страницы)

### Перечень необходимых разрешений, данных и доступов:

1. Разрешение от руководства сервиса на проведение тестирования (в случае тестирования на боевом сервере), или предоставление разработчиками SUT в тестовом режиме.
2. Предоставление данных пользователей (при необходимости для разработчиков или руководства использования в тестах определённых данных).

### Перечень и описание возможных рисков при автоматизации:

1. Проблема с разрешением на тестирование.
2. Проблема с защитой от ботов.

### Перечень необходимых специалистов для автоматизации:

1. Руководитель отдела тестирования (организационные вопросы).
2. QA-инженер, обладающий навыками работы с вышеперечисленными инструментами.

### Интервальная оценка с учётом рисков в часах:

8 часов.
